# PlotPro (DreamCity)

## Overview
PlotPro is a real estate and property layout platform specializing in plot layout visualization, project approvals, branch admin operations, customer site visits, and plot bookings.

## Platform
web

## Primary Users
1. **End Customers / Property Buyers**: Browse real estate layouts, inspect plot availability, request site visits, and send booking enquiries.
2. **Branch Administrators**: Manage assigned projects, plot statuses, enquiries, and customer site visits.
3. **Super Administrators / Supreme Admins**: Platform oversight, project approval workflows, subscription & seat management, and branch operations.

## Stack
- Frontend: React 19, Vite, React Router v7, React-Bootstrap, Lucide Icons, React Icons, GSAP
- Backend: Node.js / Express (or Python services)
- Styling: Custom CSS with Poppins font family and glassmorphism / nature-inspired dark green accents.
